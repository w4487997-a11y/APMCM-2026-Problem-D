# Q1 模型冻结与补证解释

正式模型继续采用 `hgb_gap_mix`。冻结前在 02 五折比较所有候选，只将两种直接法和两种物性法带入原 03 对照。固定 MAE 上限 2.8432 后，冻结模型的 03 MAE 为 2.4715、筛选分数为 36%。其选模证据、模型权重和最终预测全部仍可复核。

补充 03 面板是在冻结之后完成的。**条件期望罚值回归在该面板的筛选分数为 41%，MAE 为 2.4624。** 在冻结前的 02 五折，同一方法的筛选分数是 35.2%，冻结模型是 39.8%。普通带隙分解的 03 筛选分数是 37%，且 (V<5) MAE 较低。各方案的优劣和所处的实验阶段均记录于此。已经用于选模的 03 上的额外比较，不能当作独立验证择优的证据。

固定三个估计器种子时，直接梯度提升与冻结模型的五折指标一致。固定估计器种子另换两组有序对分配后，冻结模型的筛选分数分别为 40.2% 和 42.6%，直接梯度提升为 28.0% 和 26.0%。
