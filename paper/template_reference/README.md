## Extracted structure and writing guidance

The 20-page template includes:

1. Summary Sheet and English summary
2. Contents
3. Introduction
4. Description of the Problem
5. Basic Assumptions
6. Glossary and Symbols
7. Models (preparation, establishment, results, result analysis for each question)
8. Error Analysis and Sensitivity Analysis
9. Evaluation and Promotion of the Model
10. Conclusions
11. References
12. Appendix and Report on Use of AI Tools

The template's own notes specify Times New Roman typography, centered numbered equations, table titles above tables, figure captions below figures, and a team-number/page-number header from the main text onward. These are reference-template notes; where they conflict with the official competition submission specification, the official specification takes precedence.
