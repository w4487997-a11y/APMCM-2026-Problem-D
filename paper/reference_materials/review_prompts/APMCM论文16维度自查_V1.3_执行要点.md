# APMCM论文全维度自查 V1.3：执行要点与使用边界

> 来源文件：`AI论文检查！2026APMCM亚太杯论文全维度自查与获奖预测提示词.docx`（9页）
> 本文件提炼原提示词的官方评阅映射与16维度检查点。涉及官方规则的条款必须再与竞赛当年官方文件核对。

## 1. 原提示词列出的官方评阅七原则

1. 对赛题给出满意的解读方法，并解释模糊概念。
2. 明确列出建模前提和假设，并解释其合理性。
3. 通过赛题分析给出建模思路或论证模型合理性。
4. 设计能有效解决赛题的数学模型。
5. 对模型进行稳定性检验。
6. 讨论模型优缺点，并给出清晰结论。
7. 给出准确、完整的摘要。

执行时以2026 APMCM官方规则/评阅文件原文为准；本提示词是检查辅助材料，不替代官方文件。

## 2. 16个自查维度

| # | 维度 | 核查重点 |
|---|---|---|
| 1 | 摘要页与整体结构 | 摘要页位置、方法是否具体、关键结果是否量化、结构完整、章节逻辑 |
| 2 | 问题分析与重述 | 是否理解每个小问、是否解释模糊概念、是否识别数学本质、是否有整体流程图 |
| 3 | 模型假设与符号 | 假设明确且有理由、假设与模型对应、符号名称/含义/单位一致 |
| 4 | 模型建立 | 模型是否适合赛题、推导是否完整、公式规范、目标和约束明确、多问之间衔接 |
| 5 | 算法选择与求解 | 算法步骤、软件/版本、参数依据、收敛/停止条件、中间结果、复杂度和独立验证 |
| 6 | 结果分析与可视化 | 图表类型、编号、标题、坐标轴/单位/图例、正文引用、趋势解释和方案比较 |
| 7 | 稳定性检验 | 灵敏度、参数扰动、交叉验证、随机重复、误差来源和结果解释 |
| 8 | 模型评价 | 优点有证据、不足具体诚实、改进建议与适用范围明确、不夸大 |
| 9 | 创新点 | 创新点真实、与已有研究区分、效果有实证支持，不把方法组合包装成全新算法 |
| 10 | 数据处理与特征工程 | 数据质量、缺失/异常/重复、量纲、特征选择、处理流程和样本数变化 |
| 11 | 文献与AI工具列示 | 文献真实性、时效性、相关性、文内外对应、AI工具使用披露 |
| 12 | 附录与可复现性 | 核心程序、运行环境、依赖、随机种子、数据来源、代码与论文一致 |
| 13 | 英文写作与排版 | 语法、术语、字号、页眉页码、匿名信息、公式和图表编号 |
| 14 | 选题策略与赛题理解 | 是否准确理解D题、是否回答所有小问、方法是否匹配问题类型 |
| 15 | 合规与原创性 | AI使用是否符合规则、数据真实、团队对模型/实验/结论承担责任、无抄袭 |
| 16 | 整体印象与完整性 | 摘要质量、工作量、问题—分析—建模—求解—检验—评价闭环和主要贡献 |

## 3. 原提示词要求的报告结构

原文要求以六列核查表为主体：
- 一级维度；
- 二级维度/检查点；
- 核查结果；
- 问题位置；
- 问题简述；
- 整改建议。

并包含：
1. 总览；
2. 16维度检查表；
3. 严重问题清单；
4. 整体评价与改进建议；
5. HTML报告及一致样式的PDF报告。

本项目建议同时保留Markdown源报告，便于版本控制和逐项追踪。

## 4. 适配2026 D题的专项检查项

### 4.1 Q1
- V公式、五项违背度、数据划分和目标变换是否准确；
- 特征是否与最终冻结模型一致；
- 02/03验证集是否有真实V=0正例；
- MAE、RMSE、Spearman、Top-K等指标是否能由报告/脚本复现；
- 低尾/零值结论是否受样本支持；
- 预测排序价值与真实盲测表现是否区分。

### 4.2 Q2/Q3
- 候选集、决策变量和索引是否明确；
- QUBO是否与原始目标和约束数学一致；
- 惩罚系数是否有充分性证明或可验证界；
- Q2/Q3变量数、矩阵版本和候选池是否来自最终交付；
- 解码后是否重新检查合法性和原始目标；
- 量化、Ising转换、SDK执行和真机运行是否分层报告。

### 4.3 硬件精度与有限预算
- 是否报告系数量化前后差异、归零比例、合法解排序保持、regret和可行率；
- 是否报告随机种子、重复次数、预算和运行时间；
- 随机基线与模型方案是否使用同一预算和验证集；
- 03验证集上的真实V与04未知真值是否严格区分；
- 任何外部数据库是否被用于盲池身份或标签反查。

## 5. 必须由官方文件核验、不能仅凭本提示词认定的事项

原提示词附录提到字号11/12、固定页眉格式、匿名规则、AI工具正文标注/参考文献列示/详情PDF、源程序附录和提交截止时间等。它们可能是重要要求，但本项目不得仅凭该提示词认定为官方现行规定。

聊天1必须从仓库中的官方竞赛规则、论文模板说明、AI使用规定和提交通知逐项核实：
- 正文字号、字体、页数和页眉格式；
- 是否允许出现任何队伍身份信息；
- AI使用声明、正文标注、参考文献列示和详情文件的具体要求；
- 程序和支撑材料的提交方式；
- PDF命名、平台入口、时区和截止时间。

如官方材料缺失或版本不明，标记为 `UNVERIFIED`，不得写成“官方硬性要求”。

## 6. 获奖预测的使用边界

原提示词列出了奖项比例并要求预测获奖等级。此类预测无法从一份内部自查表可靠推断，也不能保证实际评审结果。

因此：
- 不输出虚假的获奖概率或保证；
- 不把原提示词中的比例直接当成官方实时统计；
- 可以给出“当前稿件质量状态、主要风险、改进优先级和证据缺口”；
- 如需要讨论奖项潜力，只能定性、审慎并明确其不代表官方评审结果。
