# AI痕迹检测提示词 V5.0：执行要点与使用边界

> 来源文件：`AI痕迹检测！2026APMCM亚太杯AI痕迹检测提示词.docx`（9页）
> 本文件提炼原提示词的检查维度和报告要求，并补充学术诚信与方法有效性边界。它不是可靠的AI作者身份检测器。

## 1. 原提示词的目标

对英文论文做逐段语言与表达诊断，定位具体问题，提供可执行修改建议。原文件要求报告包含：
1. 总体评估；
2. 详细问题清单；
3. 维度汇总；
4. 优先级修改建议；
5. 附录（高频表达、检测方法和修改原则）。

每条问题建议包含：章节/段落位置、原文摘录、问题类型、严重程度、原因分析、修改建议和修改示例。原文件提出严重/中等/轻微三级分类。

## 2. 原文件的10个检查维度

| 维度 | 检查对象 | 本项目实际采用的诊断重点 |
|---|---|---|
| 1. 英文词汇 | 高频连接词、空洞形容词、模板动词和抽象名词 | 删除无信息量套话；用可核验的对象、方法和数据替代空泛形容词 |
| 2. 句式 | 句型重复、长句、被动语态、连接词密度 | 提升可读性；主动语态与被动语态按学术语境合理使用 |
| 3. 段落 | 长度、段落结构、段首/段尾模板 | 避免每段机械地“主题句—展开—总结”；按论证功能组织 |
| 4. 逻辑 | 过度直接因果、没有不确定性、缺少作者判断 | 区分相关、预测和因果；写明证据边界、反例和不确定性 |
| 5. 作者推理与表达 | 是否有真实方法选择理由、自然解释和具体判断 | 展示团队真实做过的选择及理由；不得人为添加“人味”套话 |
| 6. 数据表述 | 小数位、误差范围、权衡和局限 | 数字精度与数据精度匹配；说明样本量、区间、重复实验和trade-off |
| 7. 图表 | 标题、坐标、单位、图例、正文引用和解释 | 图表标题表达具体发现；所有图表可追溯到脚本和数据 |
| 8. 结构 | 摘要、章节、重复引言和结论 | 结构服务于本题逻辑，不机械套用IMRaD或固定段落模板 |
| 9. 引用 | 引用位置、针对性、文献真实性 | 每条引文支持明确论点；核实作者、年份、题名、DOI和文内外一致性 |
| 10. 整体表达 | 流畅度、自然度、逻辑和细节 | 判断内容是否具体、准确、可追溯；不输出虚假的AI概率 |

## 3. 原文件中可保留的工作方法

- 从摘要页到附录逐段检查，不能只抽查引言。
- 每个问题精确定位，引用短句或段落作为证据。
- 按严重程度排序，并给出原文与建议版本的对照。
- 先处理科学事实、逻辑和引用错误，再处理句式和风格。
- 修改不得改变数据、公式、实验结果和研究结论。
- 图表标题、单位、误差棒、图例和正文引用必须一并检查。

## 4. 必须修正的使用边界

原提示词中的部分“AI概率”判断、词频阈值、段落长度标准以及“每千词必须检出若干问题”等说法，不能作为可靠的作者身份判定依据。文本风格特征不能证明某段一定由AI生成；AI检测工具也可能产生误报和漏报。

因此本项目必须遵守：

1. **不把AI检测分级或概率当作真实的作者身份结论。** 不报告“AI生成概率20%/80%”之类无可验证依据的数字。
2. **不以规避检测为目标。** 不刻意加入语法错误、无意义设问、口语词、破折号或人为不规则段落来伪装人类写作。
3. 不要求每千词必须产生固定数量的可疑点；只报告真实存在且可解释的问题。
4. 不因词汇出现在所谓“AI高频词库”就机械替换；只在表达空泛、重复或不准确时修改。
5. 不为“降低AI痕迹”修改数据、公式、结论、引用或真实研究过程。
6. 所有AI工具使用、辅助范围和人工复核应按2026官方规则如实披露；不得作虚假“未使用AI”声明。

## 5. 本项目推荐的诊断流程

### 第一轮：科学内容与证据
- 数字能否回到原始数据、脚本、日志和报告；
- 因果表述是否有设计支持；
- 预测性能与实际筛选价值是否区分；
- 04盲测真值是否始终保持未知；
- QUBO数学等价、量化可表示、SDK可运行和真机执行是否分层描述；
- 文献是否支持紧邻的论点。

### 第二轮：英文表达
- 删除空泛、重复和模板化句子；
- 把“significant improvement”替换为准确指标和比较条件；
- 让段落围绕一个可验证论点展开；
- 让不确定性和局限来自真实证据，而非为了显得“像人”而添加；
- 保持术语、时态、符号和风格一致。

### 第三轮：逐段诊断报告

建议输出：
- `paper/reviews/ai_trace_diagnostic.md`：完整问题清单；
- 可选 `paper/reviews/ai_trace_diagnostic.html`：便于浏览的报告。

每个问题记录：位置、原文、维度、严重程度、具体原因、修改建议、修改示例、是否已修改。报告只能称为“语言与表达诊断”，不能声称测得真实AI生成概率。

## 6. 修改验收标准

- 语言清楚、简洁、准确；
- 论点有数据或文献支撑；
- 研究选择和取舍有具体理由；
- 不确定性与局限真实存在且解释清楚；
- 不改动未经授权的实验事实；
- AI使用情况符合官方规则并如实披露。
