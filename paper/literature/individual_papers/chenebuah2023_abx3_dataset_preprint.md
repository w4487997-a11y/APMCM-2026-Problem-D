# Chenebuah & Chenebuah (2023): inorganic ABX3 dataset and ML benchmark preprint

**Citation:** Ericsson Tetteh Chenebuah and David Tetteh Chenebuah. “An inorganic ABX3 perovskite materials dataset for target property prediction and classification using machine learning.” arXiv:2312.11335 (2023). DOI: https://doi.org/10.48550/arXiv.2312.11335

**Reading status:** PREPRINT METADATA AND ABSTRACT REVIEWED; DATA/REPOSITORY README REVIEWED.

## Dataset and tasks
The preprint describes 16,323 inorganic ABX3 structures derived from OQMD and a processed tabular dataset with 61 generalized features. It considers formation-energy regression, band-gap regression and crystal-system classification. The abstract reports MAE values of 0.013 eV/atom for formation energy and 0.216 eV for band gap, and F1 of 85% for crystal-system classification.

## Relevance and boundary
This is a useful dataset-provenance and benchmark reference for ABX3 materials ML. It is a preprint, not automatically equivalent to a peer-reviewed journal article. Its descriptors and targets differ from Q1 v1's categorical A/B/X inputs and official V target. The public dataset and code are useful for understanding research practice, but they must not be joined against competition blind pools, used to identify hidden candidates, or used to infer any hidden labels.
