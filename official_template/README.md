# Official APMCM Template

This directory is reserved for the official 2026 APMCM submission materials.

Source archive currently stored at repository root:
- `2026 APMCM 论文提交规范、论文模板、承诺书.zip`

Expected source files to extract here:
- `2026 APMCM Summary Sheet.docx`
- `2026 APMCM Control Sheet.docx`
- `2026 APMCM Essay format and submission specifications.pdf`
- `APMCM LaTeX 模板/main.tex`
- `APMCM LaTeX 模板/apmcmthesis.cls`
- `APMCM LaTeX 模板/apmcmthesis.cfg`
- `APMCM LaTeX 模板/ControlSheet.tex`

Do not copy generated build by-products (`.aux`, `.log`, `.toc`, `.synctex.gz`) into the source-template directory. Keep the official source files unchanged. The sample PDF may be retained as a reference preview.

## Upload status

The source archive is present in the repository, but the current GitHub connection exposes text-file creation and Git object operations only; it does not provide a binary-file upload operation for DOCX/PDF assets. Therefore this README is a directory marker, not a claim that the archive has been extracted here. Extract the ZIP locally and upload the listed original files to this directory using GitHub's web UI or Git.
