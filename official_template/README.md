# Official APMCM Template

This directory contains the official 2026 APMCM submission materials extracted byte-for-byte from the organizer-provided archive.

Source archive currently stored at repository root:
- `2026 APMCM 论文提交规范、论文模板、承诺书.zip`

Extracted files:
- `Summary Sheet.docx`
- `Control Sheet.docx`
- `official_submission_specifications.pdf`
- `main.tex`
- `apmcmthesis.cls`
- `apmcmthesis.cfg`
- `ControlSheet.tex`
- `main.pdf`
- `ControlSheet.pdf`

Do not copy generated build by-products (`.aux`, `.log`, `.toc`, `.synctex.gz`) into the source-template directory. Keep the official source files unchanged. The sample PDF may be retained as a reference preview.

The source hashes are recorded in `paper/compliance/template_manifest.json`. The four official TeX source files are read-only baselines. Do not edit, rename, or overwrite them; make manuscript changes only under `paper/`.
