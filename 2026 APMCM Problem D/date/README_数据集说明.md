# 钙钛矿候选材料赛题 · 数据集说明（选手版）

## 1 空间与规模

立方钙钛矿 ABX₃ 组合空间为 **52(A) × 52(B) × 7(X) = 18,928**，是**全因子网格，无缺格**：任意 A、任意 B、任意 X 的组合都存在于数据中，`(A,B,X)` 三元组唯一数恰为 18,928、零重复。A 位与 B 位取值于同一批 52 种元素。

X 位 7 类：`O3`、`NO2`、`FO2`、`N2O`、`N3`、`O2S`、`FNO`。

## 2 目标量 V

目标材料需同时满足 `e_form < 0.21`、`1.4 ≤ gap ≤ 3.1`、`VBM > 5.73`、`CBM < 4.50`。

`V = v_form + v_gap_low + v_gap_high + v_vbm + v_cbm`，各项统一为 `v = [max(0, 偏离量/0.5)]²`：

| 项 | 对应条件 | 偏离量 |
|---|---|---|
| `v_form` | `e_form < 0.21` | `e_form - 0.21` |
| `v_gap_low` | `gap ≥ 1.4` | `1.4 - gap` |
| `v_gap_high` | `gap ≤ 3.1` | `gap - 3.1` |
| `v_vbm` | `VBM > 5.73` | `5.73 - VBM` |
| `v_cbm` | `CBM < 4.50` | `CBM - 4.50` |

`V = 0` 的材料恰有 **19 条**，正例率 **0.001004**。按 X 族分布：O3 6 条、NO2 6 条、FO2 6 条、N2O 1 条，其余三族 0 条。

**`gap = 0` 是金属性（无带隙），不是缺失值。** 全数据 18,193 条（96.1169%）为 0。按 NaN 处理会一次删掉 96% 的数据。

V 的全量分布：min 0、中位数 22.2319、max 108.9558；`V < 0.5` 100 条、`V < 1` 152 条、`V < 2` 227 条、`V < 5` 375 条。

## 5 切分口径（重要）

切分**以 `(A,B)` 元素对为单位分组**，不按单行随机打散。2,704 个 `(A,B)` 对按哈希分入 train 1,608 / val 567 / holdout 529，每个 X 族在这三档中分别有 1,608 / 567 / 529 行，于是行数为 11,256 / 3,969 / 3,703，合计 18,928。

**19 条 `V = 0` 的正例恰好落在 19 个不同的 `(A,B)` 对上**，这 19 个对全部被锁定在 holdout。结果：

- `02`、`03` 的正例数 = **0**
- `04` 的正例数 = **19**

这样一来，问题 2 / 3 的答案不存在于任何带标签文件里，只能靠代理模型排出来，无法通过查表得到。这条性质是切分设计的核心约束，请勿在复现时改动随机种子。

## 6 两条求解口径

每个问题都提供两个池，用途不同，请按题面要求选一个：

- **全量池（07 / 08）**：覆盖该问题合法的全部态（问题 2 是 2,704 态，问题 3 是 8,112 态）。真值**未公开**，需自行重建代理模型或用赛题给定模型。
- **盲池（11 / 12）**：只含 holdout 中的态（529 / 1,587 态），可用于“题目只给未标注候选”的设定。

## 7 复现

- 切分种子：`sha256("2026|<A>|<B>")` 排序定 holdout 补足位，`sha256("2027|<A>|<B>")` 排序定 val / train。
- 全部数值以 `%.6f` 固定 6 位小数落盘。由此重算 V 时会有约 1e-5 的舍入传播误差（实测最大 1.02e-5），不影响任何 `V = 0` 判定。
- `sha256_public.json` 给出每个文件的 SHA-256，可用于校验数据未被改动。
