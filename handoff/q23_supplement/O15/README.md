# O-15：四层误差归因与资源成本总账

数据来源分四类，逐项标注：

- **本机实测**：`timings.csv`、`local_sa_timing.csv`（复跑脚本 `scripts/o15_audit.py`）
- **外部实测**：复审环境 Kaiwu 记录（非本机）
- **平台记录**：O-13 六个真机任务（`O13/receipt_template.csv`、`O13/evidence/`）
- **NA / PENDING**：平台未单列或未提供的字段

本机环境：Windows，Python 3.12.14，numpy 2.x，**无 GPU、无 SDK license、未连硬件**。
计时方式：单进程 `time.perf_counter()`，每项重复 50 次（自检类 20 次）取中位数。

## 四、结论与写作口径

1. **求解成本分层**：建模/转换/适配/自检在本机为毫秒级（Q2 4.4 ms、Q3 三组 13.2 ms）；
   经典精确枚举（2,704/8,112 合法态）为 0.03/0.08 ms；本地退火为 40–50 s/模型；
   SDK CPU 每组约 20.8–21.0 s；真机总耗时 4–112 s（主要由排队/调度决定）。
2. **平台耗时不能用于论证退火参数因果**：同规模同一天，总耗时 16–112 s 而演化仅 0.7–15 ms，
   排队未单列；且 0.6991 ms 那次只返回 7 样本、0 合法。
3. **量化损失的正确表述**：原最优仍在最低能量档，损失来自按 ID 打破 6/21/24 个并列。
4. **不可声称的部分**：量子加速、真机独立发现、排队或退火参数的因果效应。
