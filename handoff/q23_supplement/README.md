## 四点五、O-14 结论（详见 `O14/README.md`）

- 盲池 11/12 **不是 23×23**：529 条分布在 52×52 上，必须用 52 宽一热 + 掩码 M=4；
- oracle-free 编码（仅线性缩放，不读枚举）下：浮点版基态唯一，本地退火 **25–27/30 种子**找到盲池最优；
- 8 位整数版 |h|≤126 可容纳，但基态并列 11–34，种子命中降至 11–16/30；
- Q3 盲池独立搜索得 **Ca–Sn–O3 1.185082**（全池为 Na–Nb–O3 0.540023，因盲池不含该配对）。

## 三点五、O-10 结论（详见 `O10/README.md`）

- 107 变量二阶投影拟合：MAE 1.1000、RMSE 1.8472、Spearman 0.9789；
- **最优改变**：Na–Nb–O3 → Rb–Ta–O3，原尺度损失 **+0.136628**，Top-1/Top-5 重合为 0（与审计独立复算一致）；
- 负系数 1,510 个 → 需 λ≈65.5 → Ising `|h|≈1648`、8 位缩放后仍 254 > 127 → **不可上 8 位硬件**；
- 对照：104 分组 `|h|=102、|J|=1`、基态唯一（唯一 8 位可交付方案）；208 联合 `|h|=161` 同样超限。
