# O-10：107 变量二阶投影对照

目标：把 08 全池 8,112 个候选的代理分，投影到 107 变量（A 52 + B 52 + X 3）的二阶加性模型，
与 104 变量分组编码、208 变量联合编码对照。

运行：`venv-mirna/Scripts/python.exe scripts/o10_projection.py`（纯 numpy，无 scipy 依赖）

---

## 一、方法

拟合形式（在合法候选上）：

```
f = c + Σα_i a_i + Σβ_j b_j + Σγ_k x_k
    + Σδ_ij a_i b_j + Σε_ik a_i x_k + Σζ_jk b_j x_k
```

- 参数 3,124 个；设计矩阵每行仅 7 个非零元（常数、A、B、X、AB、AX、BX 各一个指示）
- 用正规方程 `G=ΦᵀΦ`、`b=Φᵀy` 求解（ridge=1e-8），**拟合耗时 0.45 s**
- 每个候选 1,587/8,112 行的目标值是冻结代理分 `V_hat`

## 二、拟合质量

| 指标 | 数值 |
|---|---:|
| MAE | **1.1000** |
| RMSE | **1.8472** |
| Spearman | **0.9789** |
| 原分最优 | Na–Nb–O3（V̂=0.540023） |
| 拟合最优 | **Rb–Ta–O3**（V̂=0.676651） |
| 原尺度最优损失 | **+0.136628** |
| Top-1 / Top-5 / Top-10 / Top-25 / Top-50 重合 | **0 / 0 / 4 / 10 / 21** |

> 该结果与审计方独立复算完全一致（原尺度损失 0.136628、最优改变、Top-5 重合 0）。

## 三、三种编码对照

| 编码 | 变量 | 候选 | 非零系数 | \|h\|max | \|J\|max | 8 位可行 | 量化后最低档并列 | 最优是否保留 |
|---|---:|---:|---:|---:|---:|---|---:|---|
| **107 二阶投影** | 107 | 8,112 | 5,778（含对角） | **1,648.4** | 32.8 | **否** | 22 | **否**（损失 0.1366） |
| **104 分组（O3 组）** | 104 | 2,704 | — | **102.0** | **1.0** | **是** | **1** | **是**（损失 0） |
| **208 联合** | 208 | 8,112 | 21,735（含对角） | 161.2 | 1.0 | 否 | — | 是（浮点） |

107 投影需要经验惩罚 `λ ≈ 65.5`（合法能量观测跨度 4.30–66.71），
导致 Ising 场项 `|h| ≈ 1648`，即使按 8 位比例缩放后 `|h|` 仍达 254 → **无法上 8 位硬件**。

| 项 | 数值 |
|---|---:|
| 后端 | 本地退火（非 SDK） |
| 变量 | 107 |
| 样本数 | 300（30 种子 × 10） |
| 合法率 | 100% |

注意：返回最优 V̂=0.5400 与“拟合最优 Rb–Ta”并不矛盾——QUBO 的合法基态由拟合模型决定（Rb–Ta），
本地求解器偶尔返回 Na–Nb 只是低能量样本之一；两套“最优”因此不可混用。

## 五、结论

1. **107 变量二阶投影不可用于 8 位硬件**：二阶投影的最大问题是负系数（1,510 个）导致惩罚系数必须
   远大于合法能量跨度（λ≈65），把 Ising 场项推到 1,648，8 位适配后仍 254 > 127。
2. **投影会改变最优候选**：原尺度损失 0.1366，Top-1/Top-5 重合为 0；
   论文不能把投影结果当作原代理目标的等价求解。
3. **104 变量分组编码仍是唯一在 8 位约束下可交付的方案**（|h|=102、|J|=1、整数、基态唯一）。
4. 208 变量联合编码在浮点下正确，但 `|h|=161 > 127`，同样无法直接上 8 位硬件。
5. 因此“降位带来复杂度优势”的说法缺乏证据：变量更少（107 < 208）却付出精度与可行性代价。

## 六、两个“最优”必须分开列

| 口径 | 材料 | 数值 |
|---|---|---|
| **投影目标最优**（拟合函数 f 的最小值） | **Rb–Ta–O3** | f 最小；其原始预测分 V̂=0.676651 |
| **原始预测分最优**（冻结代理 V̂ 的最小值） | **Na–Nb–O3** | V̂=0.540023 |
| 两者原尺度差距 | — | **+0.136628** |

投影最优与原始最优不是同一个材料，Top-1/Top-5 重合为 0，说明二阶投影改变了目标函数的最优点。
论文若报告“投影 QUBO 的解”，必须注明是**投影目标**的最优，不能与 Na–Nb–O3 混写。
