### 2.3 两个必须分开的口径（关键更正）

均匀量化下，**原浮点最优仍留在最低能量档**，但按 `(能量, 候选ID)` 排序时会被 ID 居前的候选挤出第一。
所以“最优 V̂ 损失 0.647/0.645”**不是能量差**，而是**按 ID 打破并列**造成的选错：

| 问题 | 方案 | 原最优在最低档 | 按 ID 打破并列后仍第一 | 最低档并列数 |
|---|---|---:|---:|---:|
| Q2 | `qubo_x127/4` | **是** | 否 | 6 |
| Q2 | `qubo_xfloor` | **是** | 否 | 6 |
| Q3 | `qubo_x127/4` | **是** | 否 | 21 |
| Q3 | `qubo_xfloor` | **是** | 否 | 24 |

口径说明：
- `best_in_min_tier`：浮点最优候选的整数能量是否等于全池最低整数能量（衡量“是否被量化吞掉”）；
- `argmin_after_id_break`：按 `(整数能量, ID)` 字典序取第一时，浮点最优是否仍第一（衡量“能否唯一确定”）；
- `tie_ratio`：不同整数能量档数 / 候选数，比例越高说明并档越严重；
- Top-K 重合按 `(整数能量, ID)` 排序计算，K=1/5/10/25/50。

**因此论文表述应为**：8 位均匀量化后，原最优仍在最低能量档，但该档有 6/21/24 个候选并列，
按 ID 决胜会选错；分值损失来自并列决胜，而非量化改变了能量排序。

> 这解释了“排序没坏、答案却变了”。

## 四、必读声明

1. `partition_*` 与 `clip_*` 方案的代价构造**使用了组内已知最小分数**，属于**最优候选保持型编码**。
   求解器命中最优候选 **不能** 解释为“独立发现未知最优”，也 **不能** 作为量子优势证据。
2. 全池 `qubo_*` 方案未使用最优信息（纯线性缩放），但其 8 位整数化会塌档，最优不可唯一确定。
3. `direct_ising_8bit` 除排序受损外，还会出现非法态优于合法态（见 `stage2` 反例），不可用于交付。
4. 本文件所有数字可由 `scripts/o11_metrics.py` 复算，输入哈希见 `q23_fix/MANIFEST.json`。

## 六、历史 0/300 对账（P0-05）

同一标称配置（`K=52, λ=2, it=30, α=0.9`）下，`stage2` 历史记录为 **0/300、0 命中**，
`stage3` 与现行两个入口为 **8/300、8 命中**。本轮已定位并复现：

- 旧统计计数器把绝对列号再减 `n_left`，任何合法样本都无法匹配 → 恒为 0；
- **同一批 300 条样本**上用正确计数器为 **8/300**、旧计数器为 **0/300**，两入口矩阵与映射逐元素一致；
- 历史 `0/300` 的运行日志未归档 → 标 `UNVERIFIED`，新复跑登记为 `O11-R01/R02/R03`。
