# 必读声明：两档代价属于“最优候选保持型编码”

本文档回应交付通知中的专门提醒，供论文直接引用。

## 1. 编码是怎么构造的

已验证的 104 变量分区模型（Q2 的 NO2 组、Q3 的 O3/NO2/FO2 三组）使用**两档代价**：

```
cost = 4 · round( min(V̂ − min_group, Δ) / Δ ),  Δ = 0.02
```

其中 `min_group` 是该 X 族内全部 2,704 个候选的**已知最小预测分**。

因此该编码**使用了组内最优信息**：代价 0 的集合被刻意定义为“与组内最小分相差 < 0.02 的候选”，
其余全部统一为代价 4。

## 2. 因此不能声称什么

- ❌ 不能把“求解器返回组内最优候选”解释为**独立发现了未知最优解**；
- ❌ 不能把命中率、最优命中种子比例当作**量子优势**或“量子求解优于经典枚举”的证据；
- ❌ 不能把该编码下“非法态能量更高”推广为一般 QUBO 的性质——它是 λ=2 与代价∈{0,4} 共同构造出的结果。

## 3. 可以声称什么

- ✅ 在**给定该整数化编码**下，8 位系数范围（|h|=102、|J|=1）可容纳、且非法态严格劣于合法态（见证差 +2）；
- ✅ 求解器能够稳定返回**该编码的基态**（本地退火 it=300 时四模型 30/30 种子）；
- ✅ 两档编码把“最优是否保住”与“排序是否保真”区分开：最优保住（损失 0），牺牲的是非最优候选之间的分辨率。

## 4. 若要证明“独立发现”

必须改用**不依赖已知最优**的编码，例如：

- 全池候选分数按整池跨度线性缩放（本包 `qubo_x127/4`），但该方案 8 位下塌档，最优不可唯一确定；
- 或使用盲池 + 线性缩放（O-14 待做），且建模过程不得读取枚举最优。

上述两条都不满足“唯一可解 + 独立发现”同时成立，这正是本课题在 8 位硬件约束下的真实结论。

## 5. 论文建议写法

> 为保证 8 位系数下最优候选不被量化吞掉，本文采用最优保持型整数编码：以组内最小预测分为阈值构造两档代价。
> 该编码保证基态唯一且非法态严格更差，但代价是牺牲非最优候选之间的排序信息。
> 因此本文只声称“在该编码下求解器可稳定收敛到基态”，不声称求解器独立发现了未知最优，也不据此论证量子优势。
